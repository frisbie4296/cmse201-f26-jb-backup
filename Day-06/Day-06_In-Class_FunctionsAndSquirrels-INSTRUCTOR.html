Why are we doing this?#

When developing code, you will often be writing code that is meant to fit into a larger project, code that someone else (or future you) may use elsewhere, or code that needs to be used for massive amounts of data. In this assignment, you will practice writing code that others will need to use as well as code that needs to be combined into a larger project. About the Data#

You can assume that the indices for each individual list correpsond to the same squirrel. That is, the 0-th element of squirrel_shift corresponds to the same squirrel as the 0-th element of the other 4 lists.

  • squirrel_shift contains a string ‘AM’ or ‘PM’ for each element that indicates whether the squirrel was observed in the AM of the day or PM of the day.

  • squirrel_indifferent contains a string ‘True’ or ‘False’ for each element that indicates if the squirrel was indifferent to the observer (‘True’) or not indifferent to the observer (‘False’).

  • squirrel_approach is the same structure as squirrel_indifferent but indicates if the squirrel was approaching the observer (‘True’) or not (‘False’).
