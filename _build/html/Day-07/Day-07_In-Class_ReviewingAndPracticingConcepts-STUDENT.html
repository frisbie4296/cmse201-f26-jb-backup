Large Language Model Explained by ChatGPT#

What happens if we ask chatGPT to explain what chatGPT is?

Prompt: Explain using 5 bullet points for first year computational science students how large language modeling works

  • Training on Massive Data: LLMs are trained on vast amounts of text data from books, websites, and other sources. The model learns the structure and patterns in language by predicting the next word in a sentence based on previous words.

  • Neural Networks and Layers: LLMs use deep neural networks, consisting of many layers of interconnected nodes. Each layer processes and refines the input data, transforming it step by step into a more abstract representation.

  • Tokenization: Text is broken down into smaller units called tokens (like words or subwords). The model learns how these tokens relate to one another, allowing it to understand and generate coherent text.

  • Attention Mechanism: LLMs, like GPT, use an attention mechanism to focus on different parts of the input text. This allows the model to capture the relationships between words, even if they’re far apart in a sentence.

  • Generalization and Adaptation: Once trained, LLMs can generalize from their training data and apply their knowledge to a wide range of tasks, such as answering questions, translating text, or generating new sentences based on user input.

Wait, what if I don’t understand all that vocabulary?#

Prompt: I’m not sure I understand that; can you provide an analogy that most people will understand?

  • Reading Many Books: The language model (student) reads millions of books and articles to learn how sentences are structured, what words usually come after one another, and the general rules of grammar, much like a person learns to write by reading a lot.

  • Brain with Layers: The model’s “brain” is like a series of filters, where each layer picks up on different details. Early layers might recognize simple things like letters or words, while deeper layers understand bigger ideas, like the overall meaning of a sentence.

  • Breaking Down Sentences: Before the model understands text, it has to break it into chunks or “words” (tokens). Imagine you give the student a sentence one word at a time, and they slowly figure out what comes next based on what they’ve already read.

  • Paying Attention: Just like a student focuses on the important parts of a story (like remembering who the main character is), the model uses an “attention mechanism” to focus on key words and concepts, ignoring less important details.

  • Becoming a Great Writer: After all this reading and practice, the model can generate its own writing. It doesn’t just copy sentences—it mixes what it’s learned to write new sentences that fit the rules and patterns of language.

1.2 One Equal Sign Versus Two Equal Signs#

The following is crucial to know!

  1. An expression with one equals sign, for example x = 5, is an assignment. It says: “Hey Python, assign the value of 5 to the variable named x.”

  2. An expression with two equals signs, for example, x == 5, is a comparison. It says: “Hey Python, does the variable x have the value 5?” This expression returns True or False.

3. Working with loops in Python#

back to top#

Loops are extremely useful in programming. They prevent us from having to write out every instruction explicity. The caveat is you have to be careful to write the loop correctly for all cases!

In class, we covered

  1. while loops: Keep performing the code in the body of the loop while an expression is True. We sometimes refer to this as “looping by condition.”

  2. for loops. Perform the code in the body of the loop for a given number of iterations or values.

"""EXAMPLE: A typical while loop."""
# variable that we care about
x = 0

# while loop
while x < 5:
    # body of the loop
    print(x)
    x += 1

"""EXAMPLE: A typical for loop."""
# variable that we care about
x = [0, 1, 2, 3, 4]

for value in x:
    print(value)

As can be seen, the for loop produces the same output as the while loop. This is generally true, for any loop:

Any loop can be written as a for loop.

Because of this, we only focus on for loops below. Sometimes it is easier or more natural to use a different style of loop, so you should be comfortable with while loops as well.

for loops: Two Common Constructions#

We use two main types, or “constructions,” of for loops in Python.

(1) ”Loop by integer or index.” We use this to loop over the indices in an iterable object.

(Note: Iterable means a sequential data type. That is, a data type that “is able to be iterated over.” Examples include lists and tuples.)

(2) ”Loop by value.” We use this to loop over the values of an iterable object.

"""EXAMPLE: Loop by index."""
values = ["a", "b", "c", "d"]

for index in range(len(values)):
    print(values[index])

We commonly use variables like i, j, or k for the above index variable. We’ll continue to use index for pedagogy in this notebook.

"""EXAMPLE: Loop by value."""
values = ["a", "b", "c", "d"]

for value in values:
    print(value)

We commonly use variables like x, y, or val (short for value) for the above value variable. (Really, anything that’s NOT i, j, or k so we don’t confuse ourselves with the “loop by index” construction above.) We’ll continue to use value for pedagogy in this notebook.

When to use which?#

Each for loop type is useful in different situations.

To just loop over values in an iterable object, “loop by value” is sufficient and simpler to program.

You can use “loop by index” when:

  • You need to access values from multiple lists at the same index.

  • You need neighboring values from the list.

4. Connecting lists and Loops#

back to top#

We know lists are containers. Lists are also called sequential data types in Python, meaning they store a sequence of objects.

Note: Objects in a list do not have to be of the same type! (For example, [1, “two”] is a valid list.)

Lists are mutable, meaning they can be changed. (Tuples are immutable, meaning they cannot be changed.)

There are several ways to create lists in Python. Some examples are shown below.

"""EXAMPLE: Creating lists in Python."""
# by listing all values
list1 = [1, 2, 3, 4, "I", "declare", "a", "thumb", "war"]

# by using list(range(...)) to get range of values in a list
list2 = list(range(4)) # = [0, 1, 2, 3]

# by using multiplication to get a list of a certain length with a certain value
list3 = [1] * 5 # = [1, 1, 1, 1, 1] (a list of five ones)

# by converting other containers into lists
xtuple = (1, 2, 3)
xlist = list(xtuple) # = [1, 2, 3]

6. Defining and using functions (functions will not be on Quiz 1, but will likely be involved in future quizzes)#

back to top#

Like loops, functions are another extremely useful tool in programming. Functions allow use to run code in different places for different uses without rewriting the code every time!

Functions have the following key components.

  1. Input: What is “fed into” the function.

  2. Body: The “body of a function” is the code inside of the function that executes when the function is called.

  3. Output: Whatever a function “produces,” depending on its input. “Output” is also called a return value.

Here’s an example of a function that adds two numbers.

"""EXAMPLE: Defining a function in Python."""
def add(x, y):
    val = x + y
    return val

Let’s breakdown this function:

  1. Input: Two numbers, called x and y.

  2. Body: The line val = x + y. (Generally, every line that’s inside (indented) in the function is part of the body. Whether we include the return statement as part of the body depends on who you talk to and is not important here.)

  3. Output:The sum of the two numbers, called val, which is returned by the function.

KEY POINT: Variables INSIDE a function CANNOT be accessed OUTSIDE a function.

The names of the variables are “dummies” and can be changed.

KEY POINT: To get the output of a function, we must CALL the function.

You cannot access the variable val inside the function add above! To get it, you must call the function.

"""EXAMPLE: Calling a function."""
answer = add(10, 20)
print(answer)

The function above is simple and wouldn’t likely help us simplify our code as programmers. Functions that perform more complex tasks that we need to do repeteadly can significantly help us as programmers.

The Difference Between return and print#

In a few words:

  1. return produces an output that can be stored in a variable when the function is called.

  2. print displays variables to the screen. They cannot be stored by calling the function.

"""EXAMPLE: Difference between print and return."""

def return_string(string):
    return string

def print_string(string):
    print(string)

Let’s call the return_string function below:

output_from_return = return_string("hello")

Nothing happens when we call the function. The output is stored in the variable called output_from_return.

print(type(output_from_return))
print(output_from_return)

Now let’s call the print_string function below:

output_from_print = print_string("hello")

When we call this function, the string hello is printed to the screen. This happens because there is a print statement in the body of the function. When the function is called, every line in the body of the function gets evaluated.

Let’s look at the variable output_from_print:

print(type(output_from_print))
print(output_from_print)

The variable is None because the function doesn’t return anything. (In other words, it returns None.)
