# CMSE 201 - Homework 1 Rubric

In this homework assignment, students are primarily expected to practice their
python fundamentals. In particular, students will be working with lists, dictionaries,
loops, if statements, and functions. Note that they will have only very recently
been exposed to functions.

The total number of points possible in this assignment is: **22**

## Question 1: Working with lists and dictionaries (5 points)

### Part 1: Lists (4 points)

* The student should receive:
  - **1 point** for successfully writing code for bullets 2 through 5
  (4 points total).

### Part 2: Dictionaries (1 point)
* The student should receive:
  - **1 point** for correctly creating the dictionary.

## Question 2: Finding the nucleon mass (3 points)

* The student should receive:
  - **1 point** for successfully using loop function
  - **1 point** for successfully appending the effective mass in a new list 
  - **1 point** for getting the average and round correctly 

## Question 3: Fibonacci numbers (3 points)

* The student should receive:
  - **1 point** for having a working loop.
  - **1 point** for storing the Fibonacci numbers as a list and reproduce the given Fibonacci numbers
  - **1 point** for getting the Fibonacci numbers ratios correct .

## Question 4: Carbon dating (3 points)

* The student should receive:
  - **1 point** for correctly initializing the variables.
  - **1 point** for writing a functioning while loop.
  - **1 point** for finding and printing the fossil sample age 

## Question 5: Finding divisors (3 points)

* The student should receive:
  - **1 point** for writing a function that takes the correct inputs and doesn't
  throw and error when called.
  - **1 point** for correctly returning a list of numbers when the function is called.
  - **1 point** for finding the correct set of numbers.

## Question 6: Finding beer for a beginning-of-the-semester party  (5 points)

* The student should receive:
  - **1 point** for successfully working function to compute the ABV
  - **1 point** for successfully access the dictionary and computing the ABV for each variety of beer.
  - **1 point** for defining compute average ABV function and have it work correctly
  - **2 point** for using the if/elif/else condition correctly and arriving at the correct beer rating results.
